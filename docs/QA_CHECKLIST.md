# MinView Native QA 清单

本清单用于 PR 验收。作者只勾选实际执行并观察到结果的项目；未运行项必须写明原因和风险。

## 记录模板

```text
Commit SHA：
Windows 版本：
显示器与 DPI：
GPU / WARP：
测试数据：格式、数量、最大尺寸、是否为可删除副本
自动化结果：
手工结果：通过 / 失败 / 未运行
证据：日志、截图或录屏链接
```

## 自动化门禁

- [ ] `build.bat` 返回 `BUILD_OK`。
- [ ] Release 编译在 `/W4 /WX` 下零警告。
- [ ] CTest 全部通过，失败输出已保留。
- [ ] PR 上的 `PR / policy` 与 `Windows / build-and-test` 对当前 HEAD 成功。
- [ ] 从 CI artifact 启动的候选程序与被验证 SHA 一致。

## 基础冒烟

- [ ] 无参数启动、从文件启动、第二实例转发均符合预期。
- [ ] `Ctrl+O` 打开图片；PNG、JPEG、BMP、GIF、TIFF 至少各验证一个可用样本。
- [ ] 损坏文件、无权限目录或不受支持 codec 不导致崩溃。
- [ ] 窗口关闭后进程退出，后台线程不长期挂起。

## 网格与导航

- [ ] justified 等行高布局、固定间距、标签省略号和选择框正确。
- [ ] justified 末行不足时按设计拉伸填满可用宽度，不作为缺陷。
- [ ] `A` 切换方形缩略图，`L` 切换文件名标签。
- [ ] `I` 在网格、大图和全屏中展开/收起整个右侧面板，并在模式切换后保留状态。
- [ ] `N/D/S/R` 排序正确，当前选择和多选映射不漂移。
- [ ] “排序方式”等自绘二级菜单完整显示文字、快捷键、禁用态和勾选态；重复开关后 GDI/菜单资源不持续增长。
- [ ] `Ctrl+R` 递归浏览正确；无权限子目录有可接受的失败表现。
- [ ] 无直属图片的根目录递归找到图片后自动进入网格，但没有默认选中项。
- [ ] 键盘方向键、Home/End、滚轮、滚动条拖拽和多选范围正确。
- [ ] 排序、窗口 resize 与网格全屏切换重建布局后，当前选中项仍保持可见。
- [ ] 按 `docs/PERFORMANCE_BUDGET.md` 使用真实超大目录、真实 4K 目录和 30,000 张压力集检查滚动、后台加载、内存趋势和退出时间。

## 大图与全屏

- [ ] `Space` 与双击缩略图进入同一种大图模式；`Space`、`Esc` 与双击大图返回网格。
- [ ] `Enter`、`F11` 全屏切换，标题栏和任务栏恢复正确。
- [ ] 大图全屏默认隐藏工具栏，移到顶部时显示并在移开后收起；网格全屏保留工具栏。
- [ ] 双击大图返回网格；动画期间的输入不会破坏状态。
- [ ] 缩放、适应窗口、上一张/下一张和 resize 后画面正确。
- [ ] GPU 渲染可用；如能模拟，WARP fallback 也能启动。

## DPI、中文与暗色主题

- [ ] 在 100% 与 200% DPI 下检查字号、间距、42px 标签高度和点击区域。
- [ ] 跨不同 DPI 显示器移动窗口后，没有模糊、半尺寸或命中区域错位。
- [ ] 标题栏、工具栏、菜单、滚动条和背景保持暗色，背景为 `#1A1A1A`。
- [ ] 所有用户可见文案为中文，术语与快捷键显示一致。

## 元数据与格式

- [ ] SD WebUI PNG 的 prompt、negative、steps、sampler、CFG、seed、尺寸正确。
- [ ] ComfyUI PNG 的 model、VAE、LoRA、scheduler 和 prompt 正确。
- [ ] JPEG/WebP comment 解析失败时不影响正常浏览。
- [ ] 超长或含中文/emoji 的元数据不会破坏面板布局或复制。

## 高影响文件操作

仅使用已备份、可恢复的测试副本：

- [ ] 单文件删除到回收站后索引、当前项和画面更新正确。
- [ ] 多选删除后选择、索引和缓存没有错位。
- [ ] 普通 `Del` 不显示永久删除确认，仍只把明确选中的测试副本移动到回收站。
- [ ] `Shift+Del` 在任何文件系统修改前显示中文确认，明确包含“永久删除”“无法恢复”和精确目标，且默认按钮为取消。
- [ ] 永久删除确认的取消、关闭、`Esc` 和未知返回路径保持文件字节、路径、列表与选择不变。
- [ ] 只有明确确认才永久删除确认时绑定的同一有效目标；空、越界、过时或已缺失目标均 fail closed。
- [ ] “复制”写入单张图片数据，多选时禁用。
- [ ] “复制文件路径”以 Unicode 文本写入正确的一个或多个路径。
- [ ] “创建副本”不覆盖现有文件，保留格式和元数据，正确处理多选。
- [ ] OLE 左键拖拽导出包含正确文件。
- [ ] 打开所在文件夹定位正确。
- [ ] `--register` / `--unregister` 只修改当前用户范围，并可恢复原状态。

## 回归深度

- `risk: low`：自动化门禁 + 受影响文档/配置核对。
- `risk: medium`：自动化门禁 + 基础冒烟 + 所有受影响章节。
- `risk: high`：全清单；无法覆盖的硬件、codec 或数据规模必须在 PR 中列为残余风险。

QA 失败时记录最小复现和当前 SHA。修复后重跑失败用例、同区域回归以及其上游/下游状态转换。
