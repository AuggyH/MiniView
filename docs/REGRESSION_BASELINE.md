# MinView Native 回归基线（2026-07-26）

本文记录修复前已经直接观察到的问题和复现输入，用于后续 PR 判断“已修复”而不是替代当前 QA 结果。修复后必须在对应提交上重新执行并记录证据。

## P0 / P1 基线

### 返回网格访问冲突

- 环境：Windows 11、4K、200% DPI。
- 路径：递归浏览目录 → 打开嵌套图片 → 展开生成信息 → 双击大图返回网格。
- 结果：2/2 复现进程崩溃。
- 系统证据：Application Error，异常码 `0xc0000005`，故障偏移 `0x21560`。
- 修复门禁：同一路径连续 50 次无崩溃、无黑屏、无新增 WER；再执行排序和递归交叉路径。

### 空根目录递归后无法进入网格

- 数据：`D:\AIGC\Assets`，根目录无直属图片，递归可找到约 220,426 张。
- 路径：以根目录启动 → 空状态 → `Ctrl+R`。
- 结果：约 3.06 秒完成索引，但仍停留空状态，无法进入网格。
- 修复门禁：找到图片后自动进入网格，`m_grid_sel == -1`，没有默认选择；首次点击或导航再建立选择。

### 单实例转发失败

- 静态证据：`src/main.cpp` 查找 `MinViewWindow`，窗口实际注册为 `MVFrameW32`。
- 修复门禁：主实例运行时以第二进程打开另一张图片，第二进程退出且主窗口切换到目标图片。

### 网格复制使用错误路径

- 路径：在网格选择非当前大图对应项 → 右键复制。
- 结果：旧上下文菜单调用 `copy_to_clipboard()`，使用 `m_current_path`；单路径 `CF_HDROP` 还缺少列表的第二个终止空字符。
- 修复门禁：剪贴板只包含明确选择，解析结果没有垃圾第二路径；完整三类复制行为按 `PRODUCT_SPEC.md` 后续验收。

### Shift+Del 永久删除缺少确认

- 候选：`00e9de109bb12790d48e691ea9aef875729ad336`，tree `884eb060f1f1b40ac9b28fa5fa50598fd360ecde`，QA run `20260727T032141478Z`。
- 路径：在隔离副本中选中 `delete_01.png`，按一次 `Shift+Del`。
- 结果：未出现确认对话框，文件立即永久删除，原路径在回收站中无匹配项。
- 对照：普通 `Del` 正确移动到回收站，内容身份及删除后选择恢复正确。
- 修复门禁：任何永久删除 mutation 前显示中文确认；取消、关闭、`Esc` 和未知结果零 mutation；仅明确确认删除同一有效目标；普通 `Del` 保持不变。

## 性能基线

- 10,410 张真实图片、justified 网格空闲 10 秒：约占单个逻辑核心 97.9%。
- 同目录方形网格空闲：约占单个逻辑核心 5%–9%。
- 1,581 张真实 4K PNG 网格空闲：约占单个逻辑核心 19%–20%。
- 10,410 张目录跨离散视口后私有内存约 `175 → 386 → 442 → 497 MiB`，复杂混合操作曾达到约 946 MiB。
- 1,581 张真实 4K PNG 操作中私有内存约 `170 → 341.6 MiB`；排序清空缓存后下降。
- 快速滚动输入约 8–9 ms，但首帧会出现只有文件名的整屏空白，约 100–250 ms 后缩略图恢复。

## 已确认不是缺陷

- justified 布局末行不足时拉伸填满可用宽度。
- `G` 不再切换网格与大图。
- `Space` 进入统一的大图模式，不是独立临时预览。
