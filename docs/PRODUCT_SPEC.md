# MinView Native 产品交互规范

本文是 MinView Native 当前用户可观察行为的权威来源。历史报告、Issue、聊天和实现注释可以解释背景，但不得静默改变本文定义。

## 浏览模式

应用只有两种浏览模式：缩略图网格和大图模式。不存在独立的“临时预览”模式。

- 在网格中按 `Space` 或双击缩略图，进入同一种大图模式。
- 在大图模式中按 `Space`、`Esc` 或双击图片，返回网格。
- 返回网格时保留当前图片、缩略图缓存和可恢复的滚动上下文；在大图中导航到其他图片后，返回时应让当前图片可见。
- `G` 不承担模式切换功能，不得在菜单、快捷键表或提示中重新暴露。
- 300 ms 转场进行中可以忽略新的模式切换输入，但不得崩溃、黑屏或破坏状态。

## 全屏与工具栏

- `Enter` 与 `F11` 保持相同行为：在网格和大图模式中均切换全屏，不改变浏览模式。
- 网格全屏保留自绘工具栏。
- 大图全屏默认隐藏自绘工具栏；鼠标移动到屏幕顶部时显示，移开后自动收起。
- 退出全屏必须恢复窗口尺寸、位置、当前图片和网格滚动上下文。

## 右侧面板

- `I` 在网格、大图和全屏模式中均控制整个右侧面板的展开与收起。
- 面板展开状态在模式切换时保留，不为不同模式维护互相冲突的状态。
- 没有选中图片时，面板不得展示旧图片的信息。
- 图片没有生成信息时仍可展示文件名、尺寸、体积等基础信息，并明确表示没有可用生成信息。

## 网格、递归与选择

- 默认使用 justified 等行高布局；末行不足时继续拉伸填满可用宽度，这是预期行为。
- 方形缩略图是网格内的可选布局，不改变大图显示方式。
- 对没有直属图片的目录开启递归后，只要找到图片就自动进入网格。
- 递归进入网格时不默认选中第一张；首次点击、方向键或 `Home`/`End` 才建立选择。
- 递归结果仍为空时保留空状态，不制造无效选择。
- 排序、布局切换和递归重建不得把选择映射到其他文件。

## 复制与文件操作

“复制”相关操作必须区分为三个独立命令：

1. **复制**：把单张图片解码后的图片数据写入剪贴板，供图像编辑器或聊天软件粘贴；多选时禁用。
2. **复制文件路径**：以 Unicode 文本复制一个或多个完整路径，多路径之间使用换行分隔。
3. **创建副本**：在磁盘创建实际文件副本，保留原格式和元数据，采用不会覆盖现有文件的本地化重名规则；支持多选。

删除、永久删除、创建副本和 OLE 拖放必须严格使用当前明确选择，不得回退到过时的 `m_current_path`。

`Shift+Del` 永久删除必须先显示应用级中文确认，明确说明“永久删除”“无法恢复”并列出精确目标。取消、关闭、`Esc` 或任何非明确确认结果都不得修改文件、列表或选择；只有明确确认后才能永久删除确认时绑定的同一有效目标。普通 `Del` 继续移动到回收站，不显示永久删除确认。

## 格式范围

当前实现基于系统 WIC。AVIF、HEIC/HEIF、SVG、PSD、TGA、DDS 等已声明格式暂时保留，但在完成格式能力、依赖、性能、风险与工期调研前，不宣称所有 Windows 环境都能实际解码。

格式调研应给出“原生支持”“依赖系统 codec”“暂不支持”三级结论；未经决策不得为扩展格式引入第三方运行时依赖。

## 当前快捷键

| 键 | 网格模式 | 大图模式 |
|---|---|---|
| `Space` | 进入大图 | 返回网格 |
| 双击 | 进入大图 | 返回网格 |
| `Esc` | 退出全屏（如适用） | 返回网格；无网格上下文时退出全屏 |
| `Enter` / `F11` | 切换全屏 | 切换全屏 |
| `I` | 展开/收起右侧面板 | 展开/收起右侧面板 |
| `A` | 方形/justified 网格 | 无操作 |
| `L` | 显示/隐藏标签 | 无操作 |
| `N` / `D` / `S` / `R` | 名称/日期/大小/随机排序 | 无操作 |
| `Ctrl+R` | 切换递归浏览 | 无操作 |
| 方向键、`Home` / `End` | 建立或移动选择 | 浏览图片 |
| `Ctrl+O` | 打开文件 | 打开文件 |
| `Del` / `Shift+Del` | 回收站删除/永久删除 | 回收站删除/永久删除 |
