# MinView Native 性能预算与压力基线

本文定义性能验收门槛。数据集、测量方法和运行环境必须随结果一起记录；单次主观感受不能替代指标。

## 正式数据集

| 数据集 | 用途 |
|---|---|
| `D:\AIGC\Assets` | 220,000+ 图片递归索引、超大数量滚动与长期缓存趋势 |
| `D:\AIGC\ComfyUI\output` | 数千张真实 4K、约 20 MiB 级图片的解码、元数据与浏览路径 |
| 30,000 张独立 4K 压力集 | 可重复的滚动、跳转、缓存上限和退出稳定性 |

真实用户目录只读。删除、永久删除、创建副本和 OLE 拖放使用隔离测试副本。

30K 同卷硬链接夹具使用构建产物创建：

```powershell
.\build\Release\hardlink_fixture.exe `
  "D:\AIGC\ComfyUI\output" `
  "D:\AIGC\MinView-QA-30000" `
  30000
```

工具要求目标目录不存在、源图不小于 20 MiB，并在创建失败时清理不完整夹具。删除夹具前必须回读目标绝对路径、文件数、文件命名、子目录数和硬链接类型；测试后验证目标不存在且抽样源文件的链接清单已恢复。

## 验收门槛

- 220,000 张图片的递归索引时间不超过 5 秒。
- 网格完全静止且没有后台加载任务时，进程 CPU 不超过单个逻辑核心的 5%。
- 私有内存采用 512 MiB 软上限；超过预算时必须通过 LRU 或等价策略回收非当前视口缓存，而不是持续增长。
- 滚轮、滚动条拖动、选择和模式切换的输入反馈不超过 50 ms。
- 快速滚动和排序重建不得出现整屏空白；允许保留旧帧、显示稳定骨架或低清缓存。
- 30,000 张、4K、约 20 MiB/张是正式压力基线，不以 1,000 张小图替代。
- 压力流程正常退出后不得产生新的 Application Error、Windows Error Reporting 或悬挂进程。

## 测量约定

- “单核占用率”按 `CPU 时间增量 / 观测秒数 × 100` 计算，不使用任务管理器的整机归一化百分比混淆结果。
- 分别记录首次启动、冷缓存、暖缓存和已经访问多个离散视口后的指标。
- 记录私有内存、工作集、线程数、磁盘缓存文件数与体积、首帧时间和缩略图稳定时间。
- 任何缓存清空或临时移动都必须先记录精确目录和清单，移动到同卷临时位置，测试后恢复并回读验证。
- 硬链接压力集只能证明路径数量、布局和调度行为，不能替代真实独立 4K 文件的冷 I/O 与解码测试。

## 必测复杂路径

1. 递归索引 → 快速滚动 → 滚动条跨区拖动 → 排序 → 选择 → 大图 → 连续导航 → 全屏 → 返回窗口 → 返回网格。
2. 网格与大图间多次切换，同时展开/收起右侧面板并改变当前图片。
3. 冷缓存首次进入、中途跳到底部、返回顶部、重复访问相同视口和正常退出。
4. 方形与 justified 网格切换后继续滚动、排序和进入大图。
5. 隔离副本上的复制、路径复制、创建副本、回收站删除、永久删除和 OLE 拖放。
