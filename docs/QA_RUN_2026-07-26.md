## 本轮发现并修复的回归

### 排序二级菜单为空

- 复现：打开“查看 → 排序方式”，二级菜单有四行可点击区域但没有文字。
- 原因：菜单窗口子类截获 `WM_PAINT` 后只填充背景，阻止系统触发完整的 owner-draw 绘制。
- 修复：不再吞掉 `WM_PAINT`；保留暗色擦除；绘制后恢复原 GDI 对象；销毁菜单前释放 `OwnerItemData`。
- 回归：二级菜单完整显示“按名称排序 / 按日期排序 / 按大小排序 / 随机排序”、快捷键和当前勾选。

### 网格退出全屏后选中项离开视口

- 复现：在离散视口保留选中项，网格从全屏返回窗口；信息面板仍指向选中路径，但蓝色选中缩略图不在可视区。
- 原因：窗口宽度变化后重新计算网格布局，只保留旧的绝对滚动位置。
- 修复：全屏切换完成后重建布局并让当前网格选择保持可见。
- 回归：选中第 30,000 张 `qa_029999.png`，进入和退出网格全屏后均保持可见；切换日期排序后也保持可见。
